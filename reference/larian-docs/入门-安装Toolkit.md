This guide covers how to connect your Larian and mod.io accounts, redeem your key(s) on Steam, set up the necessary beta branch, and install everything you need for the Toolkit.

Connecting Your Larian and Mod.io Accounts
You’ll need both a Larian account and a mod.io account to get started.

### If You Already Have Larian and Mod.io Accounts

ⓘ Linking your accounts before attempting to publish a mod via the Toolkit reduces the chance of merge issues.
Visit Baldur's Gate 3 on mod.io and link your mod.io account to your Larian account.

### If You Don’t Have an Account on Either Platform

To create a Larian account, go to Create Account. You’ll need to verify your account via email. Once logged in, navigate to Connected Accounts and connect your Steam account.

To create a mod.io account, go to mod.io, click on Log in in the top-right corner to open the authentication method popup, and follow the steps provided.

The 'Log in' button on mod.io.
Once you’ve created a mod.io account and have a username, send that mod.io username to our community team to gain access to the Baldur’s Gate 3 mods page and guides hosted on mod.io.

Now that you've created both accounts, visit Baldur's Gate 3 on mod.io and link your mod.io account to your Larian account.

Getting the Toolkit on Steam
Before continuing with the following steps, make sure you already have the Baldur’s Gate 3 game installed on Steam.

If you were part of the alpha/beta as a mod author and want to know how to migrate your mod projects, please instead see the Migration Guide.

## Download the Baldur's Gate 3 Toolkit

You can find the Toolkit in the Steam store under Baldur’s Gate 3 Toolkit. It’s in the Tools section, and freely available.

Install the Toolkit. While you wait for the installation to complete, you can move to the next step.

The Toolkit on Steam.
If you don’t see it in your library, you might need to update your sidebar filter settings. Make sure you have Tools selected.

Making sure "Tools" is selected on Steam.

## Enable the BG3 Toolkit Data DLC

Find the Baldur’s Gate 3 game in your library. Right-click on it in the sidebar and select Properties.

Accessing the Baldur's Gate 3 properties on Steam.
In the Properties window, go to DLC, and enable the BG3 Toolkit Data DLC.

Enabling the BG3 Toolkit Data DLC on Steam.
Close the window. Steam should automatically download this extra DLC, which contains all of the Editor data necessary for the Toolkit to work.

When all of the above has finished installing, you’re ready to launch the Toolkit and move on to Getting Started: Creating a New Mod.

Getting the Toolkit on GOG
Before continuing with the following steps, make sure you already have the Baldur’s Gate 3 game installed on GOG.

## Download the Baldur's Gate 3 Toolkit

You can find the Toolkit in the GOG Store under Baldur's Gate 3 Toolkit.

Download and install the Toolkit.

The Baldur's Gate 3 Toolkit in the GOG Store.

## Enable the BG3 Toolkit Data DLC

Find your Baldur’s Gate 3 game in your library. On the game page, open the settings menu and navigate to Manage installation > Configure...

Configuring the Baldur's Gate 3 installation on GOG.
In the Configuring "Baldur’s Gate 3" window, navigate to DLC, and make sure BG3 Toolkit Data is enabled.

Enabling the BG3 Toolkit Data DLC on GOG.
Click OK to close the window.

GOG should automatically download this extra DLC, which contains all of the Editor data necessary for the Toolkit to work.

When all of the above has finished installing, you’re ready to launch the Toolkit and move on to Getting Started: Creating a New Mod.
