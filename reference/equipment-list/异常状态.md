# 装备参考 · 异常状态

> [!info] 内容
> 分类：**参考**　共 **29** 条
> 
> 数据来自作者整理的《博德之门3装备合集》。
> 用途：做装备 mod 时**找同类参考**——想知道某效果怎么实现、
> 某品质的数值区间、某部位有哪些原版装备，都可以从这里入手。

> [!warning] 本表没有 RootTemplate UUID 列
> 需要为新物品建模时，用 `query-stats.cmd entry <原版条目名>` 查原版条目，
> 从它的 `RootTemplate` 字段拿到 UUID。

| 麻痹 | 无法移动，不能做出动作、附赠动作、反应；3m内对麻痹目标必定重击。 |
|---|---|
| 束缚 | 无法移动；针对受影响个体的攻击掷骰有优势，同时该个体的攻击掷骰和敏捷豁免检定处于劣势。 |
| 睡眠 | 沉睡中的生物无法移动或做出动作。此外，生物的力量及敏捷豁免检定会自动视为失败，针对其进行的攻击掷骰会获得优势。同时，如果攻击者位于该生物1.5m的范围内则所有命中该生物的攻击均为重击。受到伤害或得到协助后效果移除。 |
| 狂怒 | 每剩余一回合，你就会有 +1 的近战武器伤害加成；最高7回合。 |
| 亢奋 | 每层提高1.5m移速，受到束缚、失能、倒伏或减速影响时将被移除。 |
| 倒伏 | 无法移动、做出动作、附赠动作或反应；力量、敏捷检定劣势；在倒伏生物3m内发起的攻击有优势；倒伏生物需要消耗一半移速才能站起来。 |
| 震慑 | 无法移动、做出动作、附赠动作或反应。 |
| 覆霜 | 敏捷豁免检定劣势。如果剩余回合大于等于7，个体必须通过体质豁免检定，否则受到1d4寒冷伤害并陷入冰冻状态，如果豁免检定成功则只受到一半伤害。在此之后冰霜融化。燃烧状态可以移除覆霜。 |
| 恐慌 | 无法移动；在进行属性检定和攻击掷骰时将处于劣势。 |
| 闪电充能 | 攻击掷骰+1，并额外造成1闪电伤害；如果身上最少有5层闪电充能，它们将在下次造成伤害时消耗，并额外造成1d8闪电伤害；每回合失去1层闪电充能。 |
| 感电 | 无法做出反应，且在进行敏捷属性检定和豁免检定时处于劣势。 |
| 触电 | 每回合受到1d4闪电伤害，无法反应，离开闪电灵光后移除。 |
| 奥术协同 | 武器攻击造成等同于受影响个体的施法关键属性调整值的额外伤害。 |
| 奥术蓄能 | 受到威胁时，受影响个体使用法术造成的伤害获得+2加值。 |
| 奥术敏锐 | 每回合增加1点法术攻击掷骰和法术豁免难度等级；个体受到伤害时持续时间减少2；最多10回合。 |
| 残响 | 在剩余的每个回合，受影响个体的力量、敏捷和体质豁免检定承受-1减值。残响剩余5或更多回合时，该个体受到1d4雷鸣伤害，且可能陷入倒伏状态。之后状态移除。免疫雷鸣伤害的生物不受此效果影响。 |
| 眩晕 | 感知豁免检定劣势；无法做出反应；使其护甲等级失去敏捷加成；盟友帮助可以移除。 |
| 燃烧 | 每回合受到1d4火焰伤害。 |
| 灼热 | 每回合受到1d4火焰伤害，可以使用灼热趋同（消耗灼热状态，发动强力攻击，下次造成火焰伤害时根据自身灼热效果，每剩余1回合额外造成1火焰伤害） |
| 濡湿 | 阻止燃烧；火焰抗性；寒冷和闪电易伤。 |
| 光耀震荡波 | 3m半径内生成光耀法球。 |
| 光耀法球 | 剩余的每个回合使受影响个体攻击掷骰-1，该个体周围区域被强光笼罩；个体每次受到伤害，持续时间减少2。 |
| 导力 | 每一剩余回合里，针对受影响个体的钝击、穿刺、挥砍伤害-1；如果回合数大于等于5，则个体受到伤害时在半径6m范围内造成1d4立场伤害；最多7回合。 |
| 精神疲劳 | 在剩余的每回合里，感知、智力以及魅力豁免检定受到一个-1的减值。 |
| 手臂酸软 | 每个剩余回合的攻击掷骰受到一个-1的减值。 |
| 麻木 | 移动速度减半；施法者对个体的攻击掷骰处于优势；得到协助或被施法者命中时效果移除。 |
| 被驱散 | 受影响个体会远离驱散他的生物，无法做出动作、附赠动作或除疾走以外的反应，此效果会在受伤后移除。 |
| 裂地 | 移动（0.5m以上）时受到1d4穿刺伤害；每移动1次，持续时间减少1回合；传送、跳跃、被推离不会触发。 |
| 捕获 | 不能移动；每回合受到1d6穿刺伤害；对受影响生物的攻击掷骰有优势；受影响生物的攻击掷骰、敏捷豁免检定劣势。 |
| 流血 | 在每回合开始时受到2挥砍伤害。在体质豁免检定中处于劣势；可通过治疗移除。 |
