# 四.新建装备
先决定你要什么装备，比如我想要一把新的长剑，那么找一把长剑的 uuid（不要用+1 长剑，
+2 长剑这种，因为基本所有的长剑都是引用这两个武器做模板的，他们有些特殊，最好不要
动。比如第三章美人鱼酒馆老板的咸味弯刀就是完全引用弯刀+2，给弯刀+2 加属性咸味弯刀

![图 3](img/萌新也能学会的自制mod教程(Ⅱ)-003.jpg)


![图 4](img/萌新也能学会的自制mod教程(Ⅱ)-004.jpg)


![图 5](img/萌新也能学会的自制mod教程(Ⅱ)-005.jpg)

⑥⑦⑧关于装备属性的，我就先不改了。
④这一行很重要，我们以这把剑为模板，那么，复制下这段字符串 id，打开 mod 教程里的
RootTemplates 文件夹（因为这把武器在 GustavDev 里所以只打开有这个后缀的就行了）
在里面搜索复制下来的字符串 id：06fbf04c-41be-4709-91df-76b4cbc9ccf5
打开这个 lsx 后缀的文件（记事本打开就行，但为了方便演示我用 vs 打开）
当然可能只有 lsf 没有 lsx 哈，那么用三个工具之一的 ExportTool 将 lsf 转成 lsx 打开就行了

![图 6](img/萌新也能学会的自制mod教程(Ⅱ)-006.jpg)


![图 7](img/萌新也能学会的自制mod教程(Ⅱ)-007.jpg)

打开 lsx
(1)这行字符串就是之前④里的字符串
打开三个工具之一的 bg3-modders-multitool
单击这个 generate，作用是生成一个字符串，这个字符串也是独一无二的，我们建立自己的武
器当然要有代表的字符串。单击字符串就能复制到粘贴板。
此时，把这个新生成的字符串替换掉原来的，同时上一部分④里的也替换掉。

![图 8](img/萌新也能学会的自制mod教程(Ⅱ)-008.jpg)

（3）这里应该是父类的 uuid，应该是关于+1，+2 武器，所以不要改动
（4）这一行的是外观 id，代表武器的外观，就比如游戏里很多长得一样的武器但他们颜色不同，
就是这行字符的效果，如果想改，那么重复④里，比如我想要+2 长剑的外观，找到+2 长剑对
应的 lsx 文件里面的这行字符，给他复制下来并粘贴到这里。就可以给武器外观替换了（不要偷
懒直接在+2 长剑的 lsx 文件上改别的东西，会出问题）当然你要想要别的普通武器就没必要再
搜索一遍了，④里直接用你喜欢的外观对应的武器的 lsx 改就行了。
（7）是游戏里武器描述文本对应的
字符串，想改汉化就和之前一样生成俩新的字符串给他俩替换了，并且记好。后面那个 version
等于几就是第几次改动，直接改成 1。
回到之前的⑤，这里同样生成一个新字符串并替换。
结果：Weapon.txt 里：

那么修改就完成了，将整个 mod 文件打包成 pak 就欧克了
